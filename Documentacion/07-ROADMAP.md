# 07 — Roadmap del proyecto

## Etapa 1 — Planificación
- Definir visión, alcance y público.
- Documentar requisitos y reglas de negocio.
- Definir recorrido del jugador.
- Crear identidad visual y prototipos.
- Definir arquitectura y modelo de datos.
- Configurar GitHub y Jira.

## Etapa 2 — Base técnica
- Crear frontend React + Vite.
- Crear backend ASP.NET Core Web API.
- Configurar SQL Server y Entity Framework Core.
- Configurar comunicación frontend/backend.
- Establecer manejo de errores y configuración segura.

## Etapa 3 — Cuenta y mascota
- Registro e inicio de sesión.
- Creación de mascota.
- Personalización inicial.
- Guardado y recuperación de partida.

## Etapa 4 — Primera escena jugable
- Habitación inicial.
- Renderizado 2D con PixiJS.
- Mascota visible y animaciones básicas.
- Interacciones con la mascota y objetos.

## Etapa 5 — Necesidades y cuidados
- Higiene, hambre y diversión.
- Acciones de cuidado.
- Evolución del tiempo offline.
- Pruebas de límites y recuperación.

## Etapa 6 — Casa e inventario
- Inventario.
- Colocación y movimiento de muebles.
- Guardado de distribución.
- Selector de habitaciones.

## Etapa 7 — Economía y tiendas
- Monedas.
- Catálogo.
- Compras validadas en backend.
- Historial de transacciones.

## Etapa 8 — Ciudad y actividades
- Mapa.
- Tiendas y lugares.
- Misiones y recompensas.
- Minijuegos iniciales.

## Etapa 9 — Colecciones y eventos
- Álbum de colecciones.
- Objetos especiales.
- Eventos temporales.
- Reglas de duplicados y cajas sorpresa.

## Etapa 10 — Social y expansión
- Amigos.
- Visitas.
- Regalos.
- Nuevas actividades y temporadas.

## Criterio de avance

Cada etapa se dividirá en entregables pequeños en Jira. Una etapa no se considerará completa solo porque el código exista: deberá compilar, probarse, revisarse y documentarse.
