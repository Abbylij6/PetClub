# 08 — Registro de decisiones

Este documento registra decisiones relevantes, su contexto y su estado. Si una decisión cambia, agregar una nueva entrada en lugar de borrar el historial.

## DEC-001 — Nombre del proyecto
- **Estado:** Aprobada.
- **Decisión:** El nombre del juego será Pet Club.
- **Motivo:** Identidad propia para el proyecto.

## DEC-002 — Especie de mascota
- **Estado:** Aprobada.
- **Decisión:** Una sola especie original de criatura fantástica con numerosas opciones de personalización.
- **Motivo:** Concentrar recursos artísticos y ampliar la variedad mediante rasgos y accesorios.

## DEC-003 — Necesidades principales
- **Estado:** Aprobada.
- **Decisión:** Higiene, hambre y diversión.
- **Motivo:** Mantener un sistema de cuidado claro y fácil de comprender.

## DEC-004 — Plataformas
- **Estado:** Aprobada como objetivo.
- **Decisión:** Comenzar por web adaptable y evaluar empaquetado móvil posteriormente.
- **Motivo:** Facilitar pruebas y llegar a varios dispositivos con una base compartida.

## DEC-005 — Tecnologías
- **Estado:** Propuesta inicial.
- **Decisión:** React, Vite, PixiJS, C#, ASP.NET Core Web API, EF Core y SQL Server.
- **Motivo:** Separar interfaz, renderizado 2D, lógica de servidor y persistencia.
- **Nota:** Revisar durante el prototipo técnico.

## DEC-006 — Funciones sociales
- **Estado:** Aprobada como etapa futura.
- **Decisión:** Amigos, visitas y regalos no serán parte del primer prototipo.
- **Motivo:** Priorizar la experiencia individual y la estabilidad del núcleo.

## DEC-007 — Economía
- **Estado:** Parcialmente definida.
- **Decisión:** Habrá moneda común y moneda especial; la progresión esencial no dependerá de pagos.
- **Pendiente:** Definir fuentes, usos, límites y equilibrio de cada moneda.

## DEC-008 — Consecuencias de ausencia
- **Estado:** Aprobada.
- **Decisión:** Las necesidades bajan con el tiempo offline, pero no habrá consecuencias irreversibles.
- **Pendiente:** Definir velocidades, límites y mecanismos de recuperación.
