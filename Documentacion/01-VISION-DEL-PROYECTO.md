# 01 — Visión del proyecto

## 1. Descripción

Pet Club es un juego de mascotas virtuales multiplataforma inspirado en los juegos sociales clásicos del género. El jugador crea una criatura fantástica original, la cuida, personaliza su apariencia, decora su hogar, explora una ciudad y participa en actividades.

Pet Club tendrá identidad, universo, personajes, ilustraciones, objetos y recursos propios. Las referencias externas se utilizarán únicamente para comprender convenciones del género, sin reproducir contenido protegido.

## 2. Objetivo

Construir una experiencia casual, creativa y progresiva en la que cada jugador pueda desarrollar un vínculo con su mascota y construir un espacio propio.

## 3. Público objetivo

Personas interesadas en mascotas virtuales, personalización, decoración, coleccionismo, exploración y juegos casuales. La experiencia deberá ser comprensible para nuevos jugadores y ofrecer objetivos a largo plazo.

## 4. Plataformas

La primera versión se planifica para navegador web con diseño adaptable a PC, notebook, tablet y teléfono. Más adelante se evaluará el empaquetado para Android e iOS.

## 5. Pilares de experiencia

- **Cuidado:** atender higiene, hambre y diversión.
- **Identidad:** crear y personalizar una criatura de una especie original.
- **Expresión:** decorar la casa y vestir a la mascota.
- **Exploración:** recorrer lugares y descubrir tiendas y actividades.
- **Progresión:** completar misiones, conseguir monedas y coleccionar objetos.
- **Continuidad:** guardar el progreso en la nube y sincronizar dispositivos.

## 6. Mascota

Habrá una sola especie original con muchas posibilidades de personalización: cuerpo y rasgos, colores, ojos, boca, expresiones y nombre. El creador mostrará una vista previa en tiempo real. La creación inicial será gratuita; los cambios posteriores podrán realizarse mediante un servicio de estilista dentro del juego.

La mascota tendrá tres necesidades principales: higiene, hambre y diversión. Sus valores evolucionarán con el tiempo, incluso durante la ausencia del jugador, con límites y mecanismos de recuperación que eviten consecuencias irreversibles.

## 7. Hogar y ciudad

El jugador comenzará con una casa de una habitación. Podrá decorar, mover objetos y desbloquear espacios adicionales. La casa será el centro de navegación hacia el mapa, inventario, misiones y actividades.

La ciudad incluirá zonas comerciales y de entretenimiento: tiendas de muebles, comida, ropa, artículos especiales, construcción, estilista, exteriores, cafetería, plaza, arcade, estadio y pesca.

## 8. Progresión y economía

El juego contemplará misiones diarias y semanales, logros, eventos, colecciones y recompensas. Habrá una moneda común obtenida jugando y una moneda especial para ciertos contenidos. La progresión esencial no dependerá de pagos.

Se estudiarán con cuidado las cajas sorpresa: probabilidades transparentes, tratamiento de duplicados y alternativas para completar colecciones sin depender exclusivamente del azar.

## 9. Funciones sociales

En etapas posteriores se evaluarán amistades, visitas a casas, regalos, mensajes y encuentros en espacios compartidos. Estas funciones no son requisito para la primera versión jugable.

## 10. Modelo de acceso

La experiencia principal será gratuita. Se contempla la posibilidad de recibir donaciones voluntarias para apoyar el mantenimiento y desarrollo. Cualquier monetización futura deberá respetar la progresión y la experiencia de juego.

## 11. Tecnologías previstas

React y Vite para interfaz; PixiJS para escenas 2D; CSS para estilos; C# y ASP.NET Core Web API para lógica de servidor; SQL Server y Entity Framework Core para persistencia. SignalR y Capacitor son opciones futuras sujetas a evaluación.

## 12. Criterios de éxito inicial

- El jugador puede crear una cuenta y una mascota.
- La partida puede guardarse y recuperarse.
- La mascota aparece en una habitación y responde a interacciones básicas.
- Las tres necesidades pueden visualizarse y actualizarse.
- El jugador puede colocar y guardar algunos objetos.
- La interfaz se adapta a escritorio y móvil.
