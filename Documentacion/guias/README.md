# Guías de desarrollo

Estas guías establecen cómo preparar el entorno y colaborar en Pet Club.

## Documentos

1. [Guía general de desarrollo](GUIA-DE-DESARROLLO.md): organización del trabajo, calidad, responsabilidades y flujo de cambios.
2. [Guía de Git y GitHub](GUIA-DE-GIT-Y-GITHUB.md): clone, status, add, commit, branches, pull, push, Pull Requests y conflictos.
3. [Guía de instalación](GUIA-DE-INSTALACION.md): herramientas y preparación del entorno.

## Orden recomendado

1. Leer la guía general.
2. Instalar las herramientas.
3. Clonar el repositorio.
4. Revisar la rama de integración indicada por el equipo.
5. Crear una rama para el cambio asignado.
6. Trabajar, probar y documentar.
7. Enviar cambios mediante Pull Request.
